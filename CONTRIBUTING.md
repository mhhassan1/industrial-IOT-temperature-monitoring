# Contributing

This repository is a simulation-first engineering portfolio. Improvements to tests, accessibility, MQTT input validation, and developer documentation are welcome. Please open an issue describing the proposed change before a significant refactor.

Do not submit private network addresses, device IDs, proprietary protocols, private operational data, credentials, or employer materials. Run `python -m unittest discover -s tests -v` before opening a pull request. Issues affecting information security should follow [SECURITY.md](SECURITY.md).
