# Before publishing this repository

- [ ] Verify employer agreements and receive any required permission to discuss the inspiration/case study.
- [ ] Ensure **no copied employer code**, source configurations, device manuals, drawings, photos, or documents.
- [ ] Check that screenshots show synthetic values, generic identifiers, and no usernames or internal addresses.
- [ ] Never commit LoRaWAN AppKeys, Microsoft identity credentials, private certificates, access tokens, or saved terminal history.
- [ ] Ensure `.env`, local databases, generated reports, and private keys are ignored by Git.
- [ ] Inspect the entire `git diff --cached` before every push, not just the README.
- [ ] Run `python scripts/prepublish_check.py`, then manually review every file; the scanner is limited.
- [ ] Enable GitHub secret scanning, push protection, and Dependabot where available.
- [ ] Verify displayed work claims match what can be personally explained and reproduced.
- [ ] Replace `YOUR_GITHUB_USERNAME` in README clone instructions after publishing.
- [ ] Keep the repository separate from site-specific installation and corporate workstations.

This is an **independent public simulation**, not a company production repository. If there is any uncertainty regarding intellectual property, do not make it public until it is resolved.
